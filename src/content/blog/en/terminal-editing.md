Editing long commands is where most people lose time. These shortcuts let you cut, delete, and recycle text at the speed of thought — no mouse needed.

## Delete by character

| Shortcut | Action |
|---|---|
| `Ctrl + D` | Delete the character **under** the cursor |
| `Ctrl + H` | Delete the character **before** the cursor (same as Backspace) |

## Delete by word

| Shortcut | Action |
|---|---|
| `Ctrl + W` | Delete the word **before** the cursor |
| `Alt + Backspace` | Delete from the cursor to the **beginning** of the word |

## Delete to line boundary

| Shortcut | Action |
|---|---|
| `Ctrl + U` | Delete everything **before** the cursor |
| `Ctrl + K` | Delete everything **after** the cursor |

## History & text tricks

| Shortcut | Action |
|---|---|
| `Alt + .` / `Esc + .` | Paste the **last argument** of the previous command |
| `Alt + <` | Jump to the **oldest** command in history |
| `Alt + >` | Jump to the **most recent** command in history |
| `Esc + T` | **Swap** the two words before the cursor |
